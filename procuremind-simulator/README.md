# ProcureMind Simulator
Static, deterministic frontend prototype (HTML5, CSS3, vanilla JS, Bootstrap 5). Open `index.html` — no server or internet needed (Bootstrap, icons and fonts are vendored in `vendor/`).

Flow: pick a scenario → Analyze Tender → review Requirements, IS Recommendations, Normative Graph, BIS status, Risks & Evidence → Accept / Modify / Reject (logged to the audit trail).
Data: `js/mock-dataset.js` (the provided mock-dataset.json bound to `window.MOCK_DATASET`). All standards/statuses are SIMULATED demo fixtures.
